## Cloud container

The cloud container ships Node 22 and pnpm 10; the project pins Node >= 24 and pnpm 11.19 (never lower the pins):

```bash
# Node 24 from nodejs.org, checksum-verified
curl -sSfL https://nodejs.org/dist/latest-v24.x/SHASUMS256.txt -o SHASUMS256.txt
f=$(grep -o 'node-v24[^ ]*-linux-x64.tar.xz' SHASUMS256.txt)
curl -sSfLO "https://nodejs.org/dist/latest-v24.x/$f" && grep " $f\$" SHASUMS256.txt | sha256sum -c
mkdir -p /opt/node24 && tar -xJf "$f" -C /opt/node24 --strip-components=1
export PATH=/opt/node24/bin:$PATH && npm i -g pnpm@11.19.0 && hash -r
# Playwright: the preinstalled Chromium
export PLAYWRIGHT_CHROMIUM_EXECUTABLE=$(ls /opt/pw-browsers/chromium-*/chrome-linux64/chrome | head -1)
# Optional: Tauri libraries for `cargo clippy --features desktop` (after `pnpm build`)
apt-get install -y libwebkit2gtk-4.1-dev libayatana-appindicator3-dev librsvg2-dev libxdo-dev
# Optional: PowerShell 7 for the release-workflow tests (POWERSHELL_EXECUTABLE=/opt/pwsh/pwsh)
```
